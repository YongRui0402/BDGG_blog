原稿、版型、建置設定都在這個 repo 裡。

- 站台:<https://yongrui0402.github.io/BDGG_blog/>
- 開發紀錄:[`docs/requirements.md`](docs/requirements.md)(為什麼這樣做)、[`docs/features.md`](docs/features.md)(一項一項怎麼做)

站還在搭建中,功能照 `docs/features.md` 的順序一項一項加上來。
